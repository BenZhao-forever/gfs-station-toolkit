站点 DMS 账号

用于司机签退（PDA 端）与打印查单（网页端），两端账号密码相同。

打印 token（DMS 网页版）

换单打印用 DMS 网页版账号（与签退同一账号密码）。登录带图形验证码，无法完全自动， 在此输一次验证码即可拿到 token；程序会定时续期保活，过期后再来登录一次。

方式一：自动登录（推荐，无人值守）

用「DMS 账号」里的账号密码 + 本地验证码识别(ddddocr)，一键登录、过期自动重登，无需人工。

方式二：手动输验证码登录

ddddocr 没装/识别不了时用。点「获取验证码」，看图输入后登录。

方式二：手动粘贴 token

从浏览器 F12 复制 Authorization 值（Bearer …），临时应急用。

测试查单

强 / 弱提醒

差值 = 应取件量 − 实取件量。

自动放行

应领−实领 < 此值、且无错扫、实领>0 时自动放行并播“签退成功”。 实领为 0 时不自动放行、播“请先收件”等人工处理。

打印方式 / 面单尺寸

浏览器静默打印用系统默认打印机，请把标签打印机设为默认；由 run.bat 的 --kiosk-printing 实现免弹窗。CLodop 需购买授权才能去掉“试用版”水印页。

强提醒：红底 + 声音 + 需放行；弱提醒：黄底。数对不上或有错扫都需人工放行/拒绝，队列暂停直到处理。

扫码枪（USB-COM）

两把枪各接一个虚拟串口(COM)，勾选后保存并重启程序生效。未配置时可用键盘/HID 扫码。
